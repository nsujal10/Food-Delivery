# 🍔 Food Delivery Backend API

A production-ready food delivery backend built using:

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Role-Based Access Control
- Payment Simulation
- Delivery Lifecycle Management
- Review & Rating System

## 🚀 Features

- User Authentication (JWT)
- Admin Controls
- Restaurant & Menu Management
- Cart System
- Order Lifecycle
- Payment Module
- Delivery Module
- Reviews & Ratings
- 22 RESTful Endpoints

## 🛠 Tech Stack

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcrypt
